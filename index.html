O que observar

O programa recebe a opção do usuário, compara essa opção com as alternativas e apresenta uma resposta. Para um menu continuar funcionando, o fluxo precisa ser executado novamente.

Exemplo simples

    print("Bem-vindo!")

Por que usar funções e validar entradas

Funções organizam responsabilidades. Validação impede que o programa execute opções inesperadas.

Função

Uma função reúne instruções que executam uma mesma tarefa. Em vez de concentrar tudo em um único bloco, cada parte recebe uma responsabilidade.

Responsabilidade

mostrar_menu() deve exibir o menu. Outra função pode cadastrar, consultar ou mostrar uma mensagem. Isso facilita leitura e manutenção.

Validação

Antes de chamar uma função, o programa verifica se a entrada é válida. Uma opção inexistente deve produzir uma orientação ao usuário.

Sem organização

print("1 - Mensagem")
opcao = input("Escolha: ")
if opcao == "1":
    print("Olá!")

Organizado em funções

def mostrar_menu():
    print("1 - Mensagem")

def mostrar_mensagem():
    print("Olá!")
Analogia: pense nas funções como setores de uma empresa. Cada setor executa uma tarefa específica, mas todos colaboram para o funcionamento do sistema.

Construindo o menu do projeto

Agora o menu permanece em execução enquanto o usuário desejar.

Mostrar menu↓Receber opção↓Analisar opção↓Executar função↓Retornar ao menu

O papel do loop

A estrutura de repetição envolve o menu e garante que ele seja exibido novamente até que a opção de saída seja escolhida.

Estrutura-base

continuar = True
while continuar:
    mostrar_menu()
    opcao = input("Escolha: ")

    if opcao == "0":
        continuar = False

Tornando o cadastro mais confiável

Complete a condição do while para que o programa continue solicitando o preço enquanto ele não for válido.

def cadastrar_produto(produtos):
    nome = input("Nome do produto: ")
    preco_valido = False
    while :
        preco = float(input("Preço do produto (maior que zero): "))
        if preco > 0:
            preco_valido = True
        else:
            print("Preço inválido. Digite um valor maior que zero.")
    produtos.append((nome, preco))
    print("Produto cadastrado com sucesso!")

Complete a condição do while para continuar a busca enquanto ainda houver produtos para verificar e o item ainda não tiver sido encontrado.

def consultar_produto(produtos):
    nome_busca = input("Digite o nome do produto: ")
    encontrado = False
    i = 0
    while :
        if produtos[i][0] == nome_busca:
            print(f"Produto encontrado: {produtos[i][0]} - R$ {produtos[i][1]:.2f}")
            encontrado = True
        i += 1
    if not encontrado:
        print("Produto não encontrado.")
